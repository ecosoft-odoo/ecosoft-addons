1. In Request > Configurations > Settings, choose Vendor Bill State: Draft
   (the default) or Posted. This setting is per company.
2. Create a request and add a line of type Vendor Bill.
3. Open the line document, enter the vendor and invoice lines, and save the bill.
4. Submit and approve the request, then click Done to process the bill.

Bills and their lines can be edited while the request is Draft or Done. Posting
is allowed only after Done. Posting errors roll back processing of the request.
Standard Accounting access rights apply; this module does not grant accounting
permissions to request users or bypass posting checks.

Request amounts are company-currency totals, including taxes; foreign-currency
bills use the bill's signed accounting total converted to a positive bill total.
The submitted amount is a snapshot. The current document amount follows the bill.

Delete or unlink a draft bill before deleting its request. Linked accounting
records are never cascade-deleted. Customer invoices and credit notes are not
supported by this module.
